# 📘 DailyLog — 日報管理システム

日々の研究・学習の記録をカレンダーベースで管理し、週ごとにPDF出力できるパーソナルツールです。

## 主な機能

### 書きやすさ
- カレンダーで日付ごとに日報を作成・閲覧（記入量に応じて色の濃さが変わる）
- 日報の項目: 本日の目的 / 行ったこと / 出来たこと / 考察・気づき / 課題点 / 次回につなげること / 参照文献・資料 / 相談・連絡事項
  - 参照文献・相談は空なら折りたたみ、必要なときだけ「＋」で開く
- **ガイド入力モード**: 1項目ずつ質問に答える形で書ける（最初の未記入項目から開始）
- **前回の「次回につなげること」を今日の「目的」へワンクリックで取り込み**
- 前回の日報パネル（土日を挟んでも直近の記入日を表示）から各項目を今日へ転記
- **クイックログ**: 一行入力して Enter で「・10:32 内容」の形で追記
- 箇条書き（`・` `-` `1.`）は Enter で自動継続、空行で終了
- 項目ごとの書き出しヒント（「想定と違ったのは、」など）と時刻挿入
- 記入進捗バー・文字数表示・自動保存時刻の表示
- ショートカット: `Alt+←/→` 前後の日 / `Alt+↑/↓` 前後の項目 / `Ctrl+Enter` 次の項目 / `Ctrl+S` 保存 / `Ctrl+P` 印刷スタジオ

### 図・表
- グラフやスクリーンショットを**ドラッグ＆ドロップ／Ctrl+V／ファイル選択**で日報に添付
  - 取り込み時に長辺1200pxへ縮小しWebPに圧縮（保存容量の節約）
- Excel・スプレッドシートの範囲を **Ctrl+V** で貼り付けると、本物の表として保存（印刷時も表組みのまま）
- 図1 / 表1 … の通し番号と説明文（キャプション）を自動で付与
- 「印刷位置」で、どの項目の下に印刷するかを指定（既定は「出来たこと」）
- 保存データ量を表示。ブラウザの保存上限に達した場合は警告

### 印刷スタジオ
- A4 実寸のライブプレビューを見ながら設定 → そのまま印刷・PDF保存
- 期間: 1日 / 週 / 月 / 任意期間（前後の期間へ移動可）
- レイアウト
  - **1日1ページ**（提出用）: 文字量に応じて自動縮小。入りきらない日は続きページへ分割し、文字が切れない
  - **2段組・連続**（論文風）: 行単位で段・ページをまたいで流し込み、紙を節約
  - **一覧表（横向き）**: 1週間を1枚で俯瞰。入らなければ日数・項目・行の単位で分割
- 図・表の入れ方を選べる
  - **別ページに大きく（既定）**: 日報の後ろに「図・表」ページを作り、紙いっぱいに配置（1ページあたり 1枚／2枚／4枚）
  - **本文の中に小さく**: 指定した項目の直下に配置。入りきらない場合は本文を優先し、図は自動で別ページへ退避
- 表紙＋サマリー: 記録日数・総文字数・日別の文字量グラフ・日別サマリー表・「次にやること」「残っている課題」・相談事項まとめ
- 載せる項目の選択、課題と次回の統合、指導者コメント欄、確認印欄、カラー/モノクロ、ゴシック/明朝、所属・氏名
- テキストでコピー（チャットやメールへの貼り付け用）
- 金曜日には週報作成を促すバナー表示

### その他
- 総記録日数・今週の記録数・連続記録日数の統計表示
- [TodoBlaster](https://github.com/728728728) 連携: 日報からタスクを直接追加

## 技術構成

- Vanilla JavaScript / HTML / CSS（フレームワーク不使用）
- ブラウザの `localStorage` にデータを保存

## 使い方

1. このリポジトリをクローンまたはダウンロード
2. `index.html` をブラウザで開く（Windowsの場合は `launch.bat` をダブルクリック）

```bash
git clone https://github.com/728728728/DailyLog.git
```

## 注意

`data.js`（実際の日報データ）は個人情報保護のため `.gitignore` で除外されています。初回起動時はデータが空の状態から始まります。
